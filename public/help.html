How To Use TaskPal

TaskPal is a browser-based task manager. Create tasks, mark them complete and keep your list in this browser without creating an account.

Add and complete tasks

  1. Type a task in the new-task field and select Add, or press Enter.
  2. Select the square beside a task to mark it complete. Select it again to mark it incomplete.
  3. Your progress shows the completed share of your current list. It does not reset each day.

Read a long task

Task cards show a two-line preview so the list stays easy to scan. Select a task to open its full text in a paper panel. Scroll inside the panel for long text, then use the close button or Escape to return to your list.

Delete and undo

Use a task’s delete button to remove it. If you delete it by mistake, select Undo while the undo message is available.

Where your list is saved

Tasks are saved on this site in the browser profile you are using. They can remain after a page reload or an ordinary browser restart when browser storage is available. There is no account, cloud backup or automatic cross-device sync. A different browser, browser profile or site address has a separate list.

Private browsing, clearing site data, storage restrictions and browser cleanup can remove or prevent saved tasks. If TaskPal reports a saving problem, keep the page open and export a backup before leaving it.

Backups and recovery

Use the Backup controls to download your task list as a file. Store that file somewhere you trust and import it when you need to restore your tasks. A downloaded backup contains the task text, so treat it as personal data.

If previous saved data cannot be read, select Download previous data to keep those original bytes for recovery. Choose Keep current tasks only when you want TaskPal to continue with the current list. A saving warning means you should keep the tab open, export a backup, and use Retry saving before leaving.

Motion and keyboard use

TaskPal respects your device’s reduced-motion preference. You can use Tab to reach the input, task controls, links and dialog controls. Task text is displayed as text, including anything that looks like HTML.
